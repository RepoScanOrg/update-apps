## Demo App Updater

This is a simple script to run scans on all our projects. This is something that has to be done every year, so it seems like a good idea to automate it.

## Usage
Uses the Java API wrapper. You need java on your machine to run it. You also will need a veracode credentials file.


## Linking

This is just to do upload&scan for static analysis. In the future. I'm going to combine this with (https://github.com/RepoScanOrg/sca-link) to do Agent-based scanning and link the apps.

## Future

Dynamic analysis is harder for all of these because we would need an active URL to run the scans. We can do some of these on demolabs, but this in general adds a lot of overhead.
